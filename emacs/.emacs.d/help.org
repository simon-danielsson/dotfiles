* Useful commands

** M-x find-file-at-point
Open a file path within a buffer (in dired or else)

** Buffer navigation

|---------------------+-------------|
| Next line           | C-n         |
| Previous line       | C-p         |
| Forwards (char)     | C-f         |
| Backwards (char)    | C-b         |
| Forwards (word)     | M-f         |
| Backwards (word)    | M-b         |
| Go to start of line | C-a         |
| Go to end of line   | C-e         |
| Previous paragraph  | M-a         |
| Next paragraph      | M-e         |
| Center cursor       | C-l         |
| Go to start of buff | Esc <       |
| Go to end of buff   | Esc >       |
| Go to line          | C-c C-g     |
| Grep find           | C-c g       |
| Kill current buffer | s-k         |
